# Fokus — CRUD & LocalStorage

An evolution of the original Fokus productivity timer, developed as part of the JavaScript module within Alura's React learning path.

While the previous version focused on DOM manipulation, events, timers, and dynamic interface updates, this version introduces data management and persistence using JavaScript.

## 🚀 What's New

This version expands the original project with:

- CRUD operations for managing tasks.
- Forms for creating and editing data.
- LocalStorage for persistent data storage.
- JavaScript services for organizing application logic.
- Dynamic DOM manipulation based on stored data.
- Data creation, reading, updating, and deletion.
- Interaction between forms, services, LocalStorage, and the interface.

## 🧠 From the Previous Version

The original Fokus project focused primarily on:

- DOM manipulation.
- Event handling.
- Countdown timers.
- Dynamic changes to HTML elements.
- Audio controls.
- Application state.

This new version takes those concepts further by introducing data persistence and application structure.

Instead of only manipulating elements on the page, the application now manages actual data and keeps that data available through LocalStorage.
